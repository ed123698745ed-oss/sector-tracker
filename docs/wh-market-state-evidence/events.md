# 市場狀態事件表

原交審窗未驗證／待 Ed 補起訖。下面自訂窗是 Eve 抽查對照，不是原表。

資金集中衡量的是：排除台積電（2330）之後，當日成交值前五大個股占其餘普通股成交值的比重，再取 5 日平均，最後做成 2005-01-01 起至當日（含）的 expanding 百分位。它描述成交值是否集中在少數股票，不是航運族群的漲跌、成分或產業狀態。2021 年 Ed 交審寫的航運約 91% 沒有附母體與起迄，不能用本年 state=2 的天數占比來核對或取代。即便在自訂的 2021 日曆年，資金集中也只占有效交易日的約三成，與 91% 不是同一個指標。

## 欄位

- 端點：起迄為 YYYYMMDD 字串閉區間。兩端都納入。起迄若不是交易日，不另往內或往外平移，只計算 docs/wh.json dates 裡落在閉區間的交易日。
- 有效交易日：有效交易日＝閉區間內下跌分數 down 不是 null 的交易日。此口徑與 stock_date=20261029 的 5093 日相同（下跌與上漲分數都已可計算）。只有資金集中分數、下跌分數仍為 null 的暖機日不進分母。
- 天數與占比：各狀態天數＝有效交易日之中 state 等於該狀態的天數。0 常態、-1 下跌瘋狂、1 上漲瘋狂、2 資金集中炒作。 占比＝該狀態天數 / 有效交易日數。非常態占比＝（下跌+上漲+集中）/ 有效交易日數。有效交易日為 0 時占比為 null。
- 資料版本：stock_date=`20261029`，規則 `2026-10-29`
